# AGENTS.md - Untold Stories

## Раздел

`untold` содержит статичные HTML-страницы с рассказами и главную страницу со списком ссылок.

## Правила

- Используйте `index.html` как список рассказов.
- Каждый рассказ храните отдельным HTML-файлом в этой папке.
- Общие стили держите в `index.css`.
- Сохраняйте минималистичную читательскую верстку, UTF-8 и адаптивность для мобильного чтения.
- Не добавляйте JavaScript без необходимости.
