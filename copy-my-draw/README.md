# Copy My Draw

Минималистичная браузерная игра без сборщика. Игрок запоминает фигуру, затем повторяет ее одной непрерывной линией. Результат считается по совпадению пиксельных масок с небольшим допуском.

## Запуск

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000`.

## Тесты

```bash
npm test
```

## Настройка

Все основные параметры игры лежат в `config.js`: таймеры, список фигур, масштаб, толщина линии, DPR-лимит и параметры алгоритма сравнения.
