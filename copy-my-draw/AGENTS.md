# AGENTS.md - Copy My Draw

## Описание приложения

«Повтори фигуру» — браузерная Canvas-игра на зрительную память и точность. Игрок запоминает случайно выбранную фигуру, а затем повторяет её одной непрерывной линией.

## Основные механики

- Фигура выбирается из списка в `config.js`, масштабируется и поворачивается случайным образом.
- После этапа запоминания игрок рисует линию мышью или касанием.
- Результат вычисляется сравнением растровых масок фигуры и рисунка по F1-метрике с настраиваемым допуском.
- Лучший результат сохраняется в `localStorage`.
- Интерфейс поддерживает русский и английский языки, а также системную, светлую и тёмную темы.

## Правила работы

- Сохраняйте приложение самодостаточным и без сборщика.
- Не добавляйте внешние зависимости без необходимости.
- Игровые параметры храните в `config.js`.
- Чистую логику размещайте в отдельных модулях `src/` и покрывайте тестами.
- Проверяйте управление мышью, касанием и изменение ориентации экрана.

## Проверка

```bash
npm test
```

Для ручной проверки запустите статический HTTP-сервер из корня репозитория и откройте `/copy-my-draw/`.
