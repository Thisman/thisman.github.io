# AGENTS.md - Основные правила работы с проектом

## Обзор проекта

Этот проект содержит веб-приложения: инструменты для оценки задач, музыкальный тренажёр и браузерные игры.

- **how-many-sp** - калькулятор сторипоинтов на основе трёх критериев
- **triangular-estimation** - оценка по трём точкам (метод PERT)
- **gamma-trainer** - тренажёр по ладовым гаммам и ступеням
- **babylon-tower** - 3D-головоломка «Pentagonal Prism Slider» на Three.js
- **my-valentine** - арканоид-игра с блоками в форме сердца
- **tic-tac-toe** - Swap-Tac-Toe: крестики-нолики с механикой swap и ИИ
- **the-maze** - Dual Grid Puzzle: головоломка с одновременным движением двух объектов
- **lightstep** - 3D-аркада: прыжки через световые паттерны на процедурных островах
- **edge-coloring** - Edgoku: раскраска рёбер сеток 5×5–9×9, шесть сложностей, уникальные пазлы с защищёнными подсказками

## Основные правила работы с HTML/CSS/JS приложениями

### 1. Структура файлов
- Каждое приложение должно находиться в отдельной папке
- Используйте стандартные имена файлов: `index.html`, `index.css`, `index.js`
- Создавайте `AGENTS.md` в каждой папке с описанием механик

### 2. HTML правила
- Используйте семантическую разметку
- Добавляйте мета-теги для корректного отображения на мобильных устройствах
- Подключайте шрифты через Google Fonts при необходимости
- Используйте UTF-8 кодировку для русского текста
- Добавляйте навигационные ссылки между приложениями

### 3. CSS правила
- Используйте современные CSS свойства (flexbox, grid)
- Применяйте адаптивный дизайн
- Используйте переменные CSS для цветов и размеров
- Добавляйте плавные переходы для интерактивных элементов
- Следите за контрастностью и читаемостью

### 4. JavaScript правила
- Используйте современный ES6+ синтаксис
- Разделяйте логику на функции
- Добавляйте обработку ошибок
- Используйте константы для магических чисел
- Комментируйте сложную логику

### 5. Общие принципы
- Каждое приложение должно быть самодостаточным
- Используйте общие ресурсы (изображения, стили) из корневой папки
- Следите за производительностью (минимизация запросов, оптимизация изображений)
- Обеспечивайте доступность (aria-labels, семантическая разметка)

### 6. Навигация
- Добавляйте ссылки между приложениями в виде иконок
- Используйте абсолютные пути для общих ресурсов
- Добавляйте ссылку на GitHub репозиторий

### 7. Документация
- Каждая папка с приложением должна содержать `AGENTS.md`
- Описывайте основные механики и алгоритмы
- Указывайте зависимости и внешние библиотеки
- Документируйте API и структуру данных

## Разработка

### Главная страница

- `index.html`, `index.css`, `index.js` — лендинг без сборки и дополнительных JS-библиотек: приветствие, диагональный блок оценок, музыкальный тренажёр, карусель игр.
- Секции занимают минимум высоту экрана (`100svh`); на узких экранах блок оценок располагается вертикально с диагональной границей. При увеличении текста контент может занимать больше экрана.
- Вертикальная прокрутка переключает секции по одному экрану: колесо/тачпад, свайп, стрелки вверх/вниз, PageUp/PageDown и пробел. Инерция одного жеста не пропускает секции; у высокого блока сначала показывается оставшаяся часть. CSS Scroll Snap выравнивает секции при обычной прокрутке и без JS. Горизонтальные свайпы карусели и масштабирование браузера сохраняются.
- `@tablescable present` печатается за 800 мс, затем за 200 мс появляется `scroll down`. Сценарий запускается один раз на загрузку документа; скролл не отменяет и не повторяет его. `prefers-reduced-motion` показывает готовое приветствие сразу.
- Фиксированная шапка появляется после первых 8 px прокрутки. Главная имеет собственную палитру; переключатель темы общих приложений сюда не подключён.
- Справа по центру закреплены четыре индикатора секций. Активный определяется текущим положением прокрутки и отмечается `aria-current`; клик сразу начинает прямой переход к выбранной секции, в том числе во время другого перехода.
- Семь игр из текущего каталога доступны в циклической карусели: центральная карточка открывает игру, боковые выбирают соседнюю. Управление: кнопки, горизонтальный свайп/перетаскивание, стрелки клавиатуры, Home/End. Автопрокрутки нет.
- Заголовки игр и теги — на английском, описания — на русском. Карточки без фона и рамок; соседние имеют `opacity: .2` и масштаб `.85`. Весь текст карточек увеличен в 1,8 раза относительно исходных размеров через `--card-text-scale`. Высота описаний одинакова для всех игр: 230,4 px на десктопе, 291,2 px на мобильных; карточки расширены и увеличены по высоте под текст.
- Нижняя область `Play` имеет тёмный фон, светлый текст и стрелку; остальная часть карточки прозрачная.
- При запуске карусель закрыта непрозрачным слоем с лоадером. Начальная расстановка выполняется без переходов; слой снимается после готовности шрифтов и двух кадров отрисовки. До этого карусель недоступна для взаимодействия; последующее перелистывание анимировано.
- Без JS карточки остаются доступны в горизонтальном списке. `.music-art` и вложенная CSS-пластинка — временный фон до получения итоговой картинки.
- Общие стили и аналитика подключаются из `/shared/`; изменения дизайна главной не вносятся в стили приложений.
- Блок планирования использует только однотонные лаймовый и лавандовый фоны с диагональной границей, без изображений.

1. Создавайте новые приложения в отдельных папках
2. Следуйте существующей структуре файлов
3. Используйте общие ресурсы из папки `images/`
4. Тестируйте на разных устройствах
5. Оптимизируйте для производительности
