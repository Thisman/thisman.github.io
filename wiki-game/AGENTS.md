# AGENTS.md — Wiki Path

Однопользовательская браузерная игра по русской Википедии. Игрок получает случайные стартовую и целевую статьи и должен дойти до цели только по внутренним ссылкам в тексте текущей статьи.

## Файлы

- `index.html` — семантическая разметка HUD, статьи, ошибок и результата.
- `index.css` — самостоятельный светлый pastel UI внешней оболочки игры.
- `index.js` — API-интеграция и полный игровой цикл без backend.

## Источник данных

Используется MediaWiki Action API `https://ru.wikipedia.org/w/api.php` с `origin=*`.

- Случайная пара: `generator=random`, `grnnamespace=0`, `grnfilterredir=nonredirects`.
- Полная статья: REST API `w/rest.php/v1/page/{title}/html`; ответ содержит исходную разметку и подключение CSS Wikipedia.
- Канонический `mw:pageId` из REST HTML является игровым идентификатором и используется для победы и повторов.

## Игровые правила

- Стартовая статья не считается переходом.
- Успешное открытие другой canonical page добавляет один переход.
- Если `pageid` уже есть в `visitedPageIds`, дополнительно добавляется один повтор.
- Переход через redirect считается одним переходом к конечной canonical page.
- Ссылка на section текущей статьи не меняет состояние и метрики.
- Во время загрузки повторные клики блокируются; ошибка не меняет текущую позицию.
- Внутренняя навигация не добавляет записи в browser history.
- Таб «Цель» показывает целевую статью без активных и визуально выделенных ссылок. Просмотр цели не меняет позицию, историю или метрики, таймер продолжает идти.

## Локальные рекорды

Каждая победа сохраняется в `localStorage` под ключом `wiki-path-records`. В записи хранятся Start/Target, время, переходы, повторы и время завершения. Незавершённые раунды не сохраняются. Popup «Рекорды» загружает записи при каждом открытии и закрывается по кнопке, `Escape` или клику по backdrop.

## Отображение контента

Статья показывается полностью из оригинального REST HTML без удаления infobox, оглавления, навигационных блоков, изображений или других частей содержимого. Документ рендерится в изолированном `iframe`, поэтому исходные стили Wikipedia не влияют на внешний UI игры.

Кликабельными на текущей статье остаются только URL вида `https://ru.wikipedia.org/wiki/<article>`. Внешние ссылки, query URL, красные ссылки и служебные пространства имён заменяются обычным текстом. Игровые ссылки всегда открываются в этом же SPA; middle click, новое окно, контекстное меню и drag для них блокируются. На табе цели все ссылки превращаются в обычный текст.

## Проверка

Запускать приложение через локальный HTTP-сервер. Проверить:

1. стартовый экран сменяется статьёй и таймер начинается только после её рендера;
2. допустимая ссылка меняет статью и добавляет один переход;
3. внешний/служебный URL не кликабелен;
4. возврат на посещённый `pageid` увеличивает «Повторы»;
5. достижение целевого `pageid` останавливает таймер и показывает полный маршрут;
6. при сетевой ошибке текущая статья и метрики не меняются, доступен повтор;
7. HUD и таблицы статьи не выходят за экран на мобильной ширине.
8. таб цели не содержит кликабельных ссылок и не меняет счётчики;
9. победа появляется в popup рекордов после перезагрузки страницы.
